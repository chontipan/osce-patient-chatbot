# OSCE Patient Sim — ระบบ Chatbot ผู้ป่วยจำลองสำหรับฝึกซักประวัติแพทย์

ระบบฝึกซักประวัติผู้ป่วยจำลอง (Standardized Patient) สำหรับนักศึกษาแพทย์และแพทย์ใช้ฝึกก่อนขึ้นสอบ OSCE

## ฟีเจอร์หลัก
1. **เลือกเคสผู้ป่วยจำลองพร้อมข้อมูลทางการแพทย์ครบถ้วน** (มีเคสตัวอย่างให้ 3 เคส: Chest Pain / RLQ Pain / Chronic Cough)
2. **สร้างและแก้ไขตัวละคร + บทพูดตามเงื่อนไข (Scripted Cues)** ได้เองผ่านหน้าเว็บ
3. **2 โหมดการทำงาน**:
   - **Offline Mode (ไม่ต้องใช้ API Key)**: ตอบตามบทพูดบังคับ (Scripted Cues) และจับคู่คำสำคัญทางการแพทย์อัตโนมัติ (CC, HPI, PMH, Meds, Allergies, FH, SH, ROS, ICE)
   - **AI Mode (Gemini API หรือ OpenAI-Compatible)**: สวมบทบาทผู้ป่วยที่เป็นธรรมชาติ ไม่หลุดคาแรคเตอร์ ไม่บอกเฉลยโรค และยังคงยึดตามบทพูดบังคับที่กำหนดไว้
4. **จับเวลาสถานี OSCE & ระบบประเมินผล**:
   - นับถอยหลังเวลาสอบ
   - ตรวจเช็ค OSCE Checklist อัตโนมัติ พร้อมให้กรอก Diagnosis & Management Plan ก่อนดูเฉลย
   - หากใช้ AI Mode จะมี **AI Examiner (อาจารย์ผู้คุมสอบ)** ช่วยประเมินทักษะการซักประวัติและการสื่อสารเพิ่มเติม
5. **รองรับเสียงภาษาไทย** (Speech-to-Text กดปุ่มไมโครโฟนเพื่อพูดถาม และ Text-to-Speech ให้ผู้ป่วยพูดออกเสียง)

## วิธีรันใช้งาน
เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรัน:
```bash
node server.js
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3456`
